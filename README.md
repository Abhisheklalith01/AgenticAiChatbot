# Agentic AI Chatbot — Level 1 Fundamentals

This repository contains the interactive tutorials, practical tasks, and starter code for **Level 1 Fundamentals** of the **AI Agents Workshop**:

- **Case Study:** Sweet Crumbs Home Bakery
- **Environment:** Google Colab / Python 3.10+
- **API:** Groq / OpenAI-compatible API

---

## 📁 Repository Contents

| File | Description |
| :--- | :--- |
| **[`day1.html`](day1.html)** | Interactive tutorial for Day 1: *How LLMs Work & Your First API Call* (Tokenization, Temperature, Context Windows, RAG basics, Hallucinations, Next-Token prediction, API mechanics). |
| **[`day2.html`](day2.html)** | Interactive tutorial for Day 2: *Prompts, Memory & Python Agents Need* (System prompts, Few-shot prompting, JSON output, Conversation history loops, Dicts, Decorators, Typing, Error handling). |
| **[`TASKS.md`](TASKS.md)** | All build tasks, 10% experimentation exercises, testing flows, and preparation assignments for Day 1 & Day 2. |

---

## 🚀 How to View the Tutorials

You can open `day1.html` and `day2.html` directly in any web browser to access:
- Interactive simulations (Token playground, Temperature slider, Context window visualizer, Prompt builder, Chat loop simulator).
- SVG animated diagrams & step-by-step walkthroughs.
- Interactive self-check MCQ quizzes with instant scoring.

## 📋 Quick Task Summary

For full details, code samples, and verification steps, see **[`TASKS.md`](TASKS.md)**.

- **Day 1 Build:** Implement an API call with role, facts, rules, and low temperature (Sweet Crumbs bakery bot).
- **Day 1 Experiments:** Temperature comparison, hallucination testing, statelessness demonstration, and token usage comparison across languages.
- **Day 2 Build:** Build a multi-turn chatbot with conversation memory trimming, dictionary lookup, `@log_call` decorator, and `try/except` error handling.
- **Day 2 Experiments:** Few-shot classification, strict JSON extraction, and conversational context retention under trimming.
- **Prep for Level 2 (Day 3):** Prepare your business catalogue as a Python dictionary and 10 common customer queries.
